# `what` — An enhanced `which` for Archlinux


### Usage
```shell
$ what which
/usr/bin/which: which 2.21-6 "A utility to show the full path of commands"
```


### Installation

- [Read & save](https://raw.githubusercontent.com/grandchild/what/main/what)
- `chmod +x what`
